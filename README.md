# RPM — Rynnoo's Program Manager

Download and update Rynnoo's programs and individual LiveSplit plugins from one launcher.

[Download the latest launcher](https://github.com/Rynnoo/rpm-releases/releases/latest)

Extract the public RPM ZIP and open **RPM.Launcher.exe**. No GitHub account is needed.
Launcher updates install automatically when RPM closes. Program updates are selected individually.
Use **Settings → Start with Windows** to select programs to launch when you sign in.

Public catalog: https://raw.githubusercontent.com/Rynnoo/rpm-releases/main/rpm/catalog.json
